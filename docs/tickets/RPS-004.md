# RPS-004 — Katalog dan mesin ketersediaan slot

Status: **Belum dimulai**

Prioritas: **P0**

Dependensi: RPS-003

## Tujuan dan cakupan

Implementasikan GET catalog dan GET availability. Katalog anonim memakai data publik
read-only; sesi memakai unit workspace sendiri. Slot dihitung server menurut WIB dan PRD.

## Kriteria penerimaan

- [ ] Membaca katalog anonim tidak membuat workspace atau cookie sesi.
- [ ] Availability memerlukan sesi; tidak membuka nama/nomor pelanggan atau booking asing.
- [ ] Tanggal hari ini sampai D+14 inklusif, jam 10.00–23.00, grid 30 menit,
  durasi 60/120/180 menit dan lead time 15 menit dihitung dari waktu server.
- [ ] Tanggal invalid, format ambigu, durasi asing dan ID unit tidak valid ditolak.
- [ ] Unit nonaktif tidak dapat dipesan. Unit asing mengembalikan 404.
- [ ] Interval [mulai, selesai) mencakup overlap sebagian; sesi bersebelahan diperbolehkan.
- [ ] Booking non-cancelled dan blok menutup slot; cancelled tidak menutupnya.
- [ ] Respons menyertakan waktu server, tarif/quote dan alasan slot tidak tersedia,
  tanpa menyiratkan slot sedang ditahan.
- [ ] Ketersediaan tidak berubah karena zona waktu perangkat browser.

## Verifikasi tanpa unit test

Gunakan D+1 dan unit sementara. Periksa overlap 19.00–21.00 dengan 20.30, slot 21.00,
unit berbeda, blok, cancelled, unit nonaktif, batas 22.30 dan tanggal tidak valid.
Pastikan jumlah workspace tidak berubah setelah banyak GET publik.

Untuk implementasi, `npm run check` harus lolos. Gunakan database/port sementara bila
relevan, periksa kembali [PRD](../../PRD.md) dan [aturan proyek](../../AGENTS.md).
Kerjakan tiket ini saja; fitur tiket berikutnya tidak otomatis ikut dikerjakan.
