# RPS-006 — Landing, arah visual dan kerangka frontend

Status: **Belum dimulai**

Prioritas: **P0**

Dependensi: RPS-003, RPS-004

## Tujuan dan cakupan

Gunakan skill frontend-design untuk membuat arah visual Sesi Play dan landing bisnis.
Siapkan shell navigasi, pemulihan sesi, masuk/ganti peran, logout dan halaman tujuan.

## Acuan visual yang sudah disiapkan

Baca [DESIGN.md](../../DESIGN.md) dan [prototype tiga layar](../design/README.md).
Arah visual, token, HTML/CSS dan screenshot disiapkan terpisah dari aplikasi. Gunakan
sebagai acuan; hubungkan ke API sesuai PRD. Data prototype tidak boleh menjadi logika bisnis.
Tiket tetap **Belum dimulai** sampai implementasi dan seluruh kriteria di bawah terpenuhi.

## Kriteria penerimaan

- [ ] Landing memperlihatkan identitas contoh, fasilitas, unit/tarif, jam buka,
  cara booking dan CTA pelanggan/pemilik. Tidak ada ulasan atau klaim bisnis palsu.
- [ ] Arah tipografi, warna dan layout dicatat; tampilan matang, tidak penuh neon/dekorasi.
- [ ] Landing tanpa sesi memuat katalog publik dan tidak membuat workspace otomatis.
- [ ] CTA membuat sesi sesuai role, lalu menuju alur yang benar; ganti peran memakai
  workspace yang sama dengan penjelasan bahwa ini simulasi.
- [ ] Refresh/deep link memulihkan sesi; loading, error, retry dan expiry terlihat jelas.
- [ ] Navigasi sesuai role; proteksi server tetap berlaku pada request langsung.
- [ ] Logout memakai konfirmasi bahwa data demo dihapus, lalu kembali ke landing.
- [ ] Nyaman pada 360/768/1280px, keyboard dan reduced motion; tidak scroll horizontal.
- [ ] Penjelasan demo, data sementara dan pembayaran di tempat terlihat sebelum mencoba.

## Verifikasi tanpa unit test

Jalankan build produksi di browser. Periksa landing tanpa cookie, kedua CTA, refresh,
role switch, logout, error API dan sesi habis. Periksa tiga ukuran layar dan fokus keyboard.
Halaman booking/agenda lengkap dikerjakan di tiket berikutnya.

Untuk implementasi, `npm run check` harus lolos. Gunakan database/port sementara bila
relevan, periksa kembali [PRD](../../PRD.md) dan [aturan proyek](../../AGENTS.md).
Kerjakan tiket ini saja; fitur tiket berikutnya tidak otomatis ikut dikerjakan.
