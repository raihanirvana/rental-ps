# RPS-012 — Integrasi, keamanan dan kesiapan demo

Status: **Selesai**

Prioritas: **P0**

Dependensi: RPS-007, RPS-008, RPS-009, RPS-010, RPS-011

## Tujuan dan cakupan

Tutup celah integrasi dan keamanan, jalankan seluruh skenario PRD, lalu dokumentasikan
hasil serta keterbatasan nyata. Gunakan smoke check API/browser, tanpa membuat unit test.

## Kriteria penerimaan

- [x] Mutasi asing ditolak berdasarkan origin; JSON diwajibkan untuk endpoint berbody.
  Tidak ada cookie CORS wildcard. Mode dev tetap bekerja dengan Host asli.
- [x] Rate awal: 30 sesi/IP/10 menit, 300 API/IP/menit; maksimal 200 workspace aktif dari
  database. Kapasitas diperiksa atomik, role switch tetap bisa saat penuh.
- [x] Trust proxy terbatas, Secure HTTPS, CSP aset lokal, anti-iframe, no-store data personal,
  batas body 100 KB dan error tanpa stack trace/PII terverifikasi.
- [x] Semua skenario PRD bagian 13 diuji, termasuk race booking/blok/status/reset,
  replay key, rollback, expiry, snapshot dan dua pengunjung.
- [x] Input markup terlihat sebagai teks; SQL wildcard/payload tidak menjadi injeksi.
- [x] Loading, error/retry, keyboard/dialog, reduced motion dan 360/768/1280px diperiksa.
- [x] Build produksi serta mode dev lolos alur utama; console bebas error yang belum dijelaskan.
- [x] README, API.md, DATABASE.md dan VERIFICATION.md memuat konfigurasi, kontrak,
  hasil nyata, browser yang diuji dan batas demo. Tidak mengeklaim printer/browser lain.
- [x] `npm run check` lolos; tidak ada secret, database runtime atau unit test baru.

## Verifikasi tanpa unit test

Jalankan checklist pada database/port sementara dengan dua cookie jar/browser context.
Simpan langkah atau script integrasi yang dapat diulang tanpa hardcoded tanggal atau
menyentuh data pengembangan. Catat apa yang belum diuji; jangan menandainya lulus.

Untuk implementasi, `npm run check` harus lolos. Gunakan database/port sementara bila
relevan, periksa kembali [PRD](../../PRD.md) dan [aturan proyek](../../AGENTS.md).
Kerjakan tiket ini saja; fitur tiket berikutnya tidak otomatis ikut dikerjakan.

### Perubahan

- Middleware baru: `security-headers.js` (CSP aset lokal tanpa `unsafe-inline`, `frame-ancestors
  'none'`, `X-Frame-Options: DENY`, `nosniff`, `Referrer-Policy`, COOP/CORP, `Permissions-Policy`,
  HSTS hanya `request.secure`), `origin-check.js` (mutasi wajib origin aplikasi/`ALLOWED_ORIGINS`,
  lintas situs tanpa Origin ditolak), `json-only.js` (415 untuk body non-JSON), `rate-limit.js`
  (fixed window per IP di memori: 30 sesi/10 menit, 300 API/menit, `Retry-After`).
- Kapasitas 200 workspace aktif dihitung dari database di dalam transaksi login (setelah membersihkan
  workspace kedaluwarsa); ganti peran tidak melewati pemeriksaan ini. 503 `DEMO_CAPACITY` + `Retry-After`.
- Config/env: `ALLOWED_ORIGINS`, `DEMO_SESSION_LIMIT`, `API_RATE_LIMIT`, `DEMO_MAX_WORKSPACES`.
- `npm run verify:api` (`scripts/verify-api.js`, `scripts/verify/*`): integrasi API berulang pada
  server proyek asli, SQLite/port sementara, dua proses untuk race, server proxy tepercaya dan server
  batas kecil; tanggal dari server; fixture DB hanya untuk keadaan yang tidak bisa dibuat via API.
- Dokumen: `docs/API.md`, `docs/DATABASE.md`, `docs/VERIFICATION.md`, README (env, keamanan, verifikasi).

### Temuan selama pengerjaan

- Skrip verifikasi semula bernama `.mjs` sehingga tidak tercakup ESLint (`scripts/**/*.js`); diganti `.js`
  dan dipecah sampai lolos batas 25 baris/100 karakter.
- Suite browser lama RPS-006/007/009 memuat ekspektasi halaman placeholder dan slot sore hari; disesuaikan
  (D+1, halaman yang kini ada) sebelum regresi. Bukan regresi aplikasi.
- Proses Vite lain di port 5173 (dimulai 21.56, bukan milik tiket ini) tidak dihentikan.

### Batasan

- Hanya Chromium headless; Firefox/Safari/pembaca layar/perangkat fisik belum diuji.
- HTTPS hanya disimulasikan lewat proxy loopback; deployment publik di RPS-013.
- Rate limit per proses di memori; satu instance penulis SQLite.
- Harness browser (Playwright di lingkungan pengembang) tidak disimpan di repo; langkahnya dicatat di
  VERIFICATION.md. `verify:api` disimpan dan bisa diulang.

## Review lanjutan

[Review RPS-012](../REVIEW-RPS-012.md): charset/kompresi/URL rusak kini 400/415, log API
tidak memuat pesan mentah. Harness mengisolasi environment, membersihkan startup gagal,
menjaga log sebelum restart dan memakai fixture expiry relatif yang mengidentifikasi workspace
lewat unitnya. Suite diperluas menjadi **72/72 lulus**, termasuk rollback, input terkompresi,
kapasitas antarproses, allowlist dan rate proxy. Regresi browser 33 kelompok dengan batas
default, CSP/form lintas origin/skrip inline serta Vite/StrictMode lulus. Tidak deploy pada tiket ini.
