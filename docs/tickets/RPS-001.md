# RPS-001 — Fondasi aplikasi dan standar kode

Status: **Selesai**

Prioritas: **P0**

Dependensi: —

## Tujuan dan cakupan

Siapkan React + Vite, CSS, Express dan JavaScript ESM. Satu server produksi melayani
frontend serta `/api`. Pilih dan pin versi Node/dependency yang benar-benar kompatibel
dengan `node:sqlite`. Buat `.env.example`, script dev/build/start/check dan dokumentasi lokal.

## Kriteria penerimaan

- [x] Instalasi bersih dan langkah menjalankan aplikasi terdokumentasi serta berhasil.
- [x] `npm run check` menjalankan pemeriksaan format, ESLint dan build tanpa unit test.
- [x] ESLint membatasi semua fungsi/callback/JSX maksimal 25 baris, termasuk komentar
  dan blank line; panjang baris maksimal 100 karakter. Tidak ada pengecualian pengakalan.
- [x] Dev menjalankan UI dan API; proxy mempertahankan Host agar pemeriksaan origin kelak bekerja.
- [x] Build produksi dapat disajikan Express; URL halaman frontend bisa di-refresh.
- [x] `/api/health` merespons JSON; path API tidak dikenal tidak mengembalikan HTML SPA.
- [x] `.env`, dependency, output build dan file database tidak masuk Git.

## Verifikasi tanpa unit test

Jalankan install bersih, check, dev dan build produksi pada port sementara. Buktikan
aturan 25 baris menangkap fungsi 26 baris melalui file sementara lalu hapus file itu.
Coba health, URL frontend langsung dan API 404. Belum ada fitur booking atau deployment.

Untuk implementasi, `npm run check` harus lolos. Gunakan database/port sementara bila
relevan, periksa kembali [PRD](../../PRD.md) dan [aturan proyek](../../AGENTS.md).
Kerjakan tiket ini saja; fitur tiket berikutnya tidak otomatis ikut dikerjakan.

## Bukti penyelesaian

Diverifikasi 15 Oktober 2026 dengan Node 22.20.0 / npm 10.9.3 (macOS).

### Perubahan

- `package.json` (ESM, `engines` node >=22.13.0), `package-lock.json`, `.nvmrc` 22.20.0,
  `.npmrc` (`engine-strict`, `save-exact`; baris registry publik dikomentari atas permintaan
  pemilik). Versi dipin persis sesuai kombinasi yang sudah berjalan di proyek POS:
  Express 5.3.0, React/React DOM 19.3.0, Vite 7.3.7, @vitejs/plugin-react 5.2.0,
  ESLint 10.12.0, @eslint/js 10.0.1, react-hooks 7.1.1, react-refresh 0.4.26, globals 16.5.0,
  Prettier 3.9.10, concurrently 9.2.5. `.env` dibaca dengan `process.loadEnvFile` (tanpa dotenv).
- `node:sqlite` dicek di Node 22.20.0: `DatabaseSync(':memory:')` jalan, SQLite 3.50.4,
  dengan `ExperimentalWarning` (wajar di Node 22).
- Server: `server/config.js`, `app.js`, `index.js`, `routes/health.js`,
  `middleware/request-context.js`, `middleware/errors.js`, `lib/http-error.js`.
  `/api` memakai JSON 100 KB, health, lalu 404 JSON; frontend statis + fallback `index.html`.
- Client: `client/index.html`, `vite.config.js` (proxy `/api` dengan `changeOrigin: false`),
  `src/main.jsx`, `App.jsx`, `useHealth.js`, `lib/api.js`, `styles.css` (shell sementara;
  arah visual di RPS-006).
- `eslint.config.js`, `.prettierrc.json`, `.prettierignore`, `.env.example`, README.

### Batasan

- Diuji dengan curl/HTTP, belum di browser sungguhan. UI masih shell sementara.
- Saat verifikasi awal belum ada repo Git; pada review repo/remote rental-ps sudah tersedia.
- Health belum memeriksa database (skema/koneksi dibuat di RPS-002).
- Registry default mesin ini (mirror korporat) sempat 404 untuk `express@5.3.0`; lockfile
  saat ini ter-resolve ke `registry.npmjs.org`.
- Fallback SPA juga menjawab path aset yang tidak ada dengan `index.html`; header keamanan,
  origin check dan rate limit belum ada (RPS-003/RPS-012).
