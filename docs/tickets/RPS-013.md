# RPS-013 — Deployment gratis dan panduan presentasi

Status: **Dikerjakan**

Prioritas: **P1**

Dependensi: RPS-012

## Tujuan dan cakupan

Siapkan satu Node Web Service untuk frontend/API, dokumentasi dan konfigurasi deployment.
Target awal Render Free; verifikasi ketersediaan paket/kuota/runtime pada saat pelaksanaan.
Tiket belum selesai hanya karena file konfigurasi hosting sudah dibuat.

## Kriteria penerimaan

- [ ] Pilihan hosting gratis dan batas akun diperiksa; tidak membuat layanan/disk berbayar.
- [ ] Runtime mendukung node:sqlite; build/start, PORT, bind address dan NODE_ENV benar.
  SQLite memakai storage sementara dengan batas yang dinyatakan jelas.
- [ ] Secret lewat environment hosting, bukan Git; trust proxy disesuaikan dan diuji nyata.
- [ ] URL HTTPS publik memuat landing, deep link dan API pada satu origin.
- [ ] Cookie Secure, sesi, booking, konflik slot dan dua pengunjung diverifikasi live.
- [ ] Setelah kehilangan database, UI menawarkan demo baru tanpa loop/error yang menyesatkan.
- [ ] README mencantumkan URL, langkah deploy/redeploy, konfigurasi, batas sleep/kuota,
  kemungkinan kehilangan data dan cara memulihkan demo.
- [ ] Ada panduan presentasi singkat: booking pelanggan → agenda owner → konflik → reset.
- [ ] Jika kuota/otorisasi/deploy platform menghalangi, catat blocker dan status belum selesai;
  jangan mengklaim live atau otomatis beralih ke paket berbayar.

## Verifikasi tanpa unit test

Periksa URL publik dari browser dan curl, lakukan booking D+1, replay key, role switch,
workspace kedua dan reset. Periksa header HTTPS dan refresh deep link. Verifikasi restart
hanya pada service demo yang dibuat untuk proyek ini; jangan mengganggu service POS.

Untuk implementasi, `npm run check` harus lolos. Gunakan database/port sementara bila
relevan, periksa kembali [PRD](../../PRD.md) dan [aturan proyek](../../AGENTS.md).
Kerjakan tiket ini saja; fitur tiket berikutnya tidak otomatis ikut dikerjakan.

## Bukti penyelesaian

Konfigurasi `render.yaml`, script deploy khusus repo rental-ps (Free, tanpa disk), pin
Node 22 dan panduan deployment/presentasi sudah disiapkan. Verifikasi URL publik masih
berjalan; status belum Selesai sampai bukti live dan pemulihan kehilangan database ada.
